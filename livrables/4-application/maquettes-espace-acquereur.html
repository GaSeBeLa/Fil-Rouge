Maquettes de l'espace acquéreur

Six écrans d'un futur site, dessinés pour le dossier de conception (BC03). Le projet ne livre pas de site : chaque maquette dit quelle route de l'API la nourrit.

Elles suivent la note d'accessibilité PSH : étiquettes visibles, cibles d'au moins 44 px (le minimum WCAG est de 24 px), erreurs dites en texte, texte alternatif des photos.

Activer mon compte

API : le manager obtient le code par POST /users/{id}/activation-code (7 jours) ; le particulier l'envoie à POST /auth/activate, qui rend aussitôt un jeton de connexion.
